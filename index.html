Your card files live here

Import a CSV once and it stays saved on this device. Bring in as many as you like and switch between them from the menu above.

Columns it understands: Card Name, Card No., Set, Set Code, Rarity, Condition, Price, Qty, Link. Only the name is needed.

Label design

Show on label

Set uses the short set code (like OP05 or SVI) when your CSV has a "Set Code" column, and shows it with the number, e.g. "OP05 · 119". Without a code it shows the set name, shortened if it's long.
